### Task 2: Статистическое сравнение и короткий A/A–A/B

**Files:** два статистических пакета из таблицы; в каждом дополнительно

**Interfaces:**
- `paired_difference(loss_a: Sequence[float], loss_b: Sequence[float],
  unit_ids: Sequence[str], *, seed: int, n_resamples: int,
  confidence: float) -> DifferenceEstimate` в paired starter.
- `DifferenceEstimate`: `effect: float`, `lower: float`, `upper: float`,
  `unit_count: int`, `resample_count: int`. Estimand — среднее по независимым units
  их средних paired differences `loss_b - loss_a`; отрицательное = меньше loss у B.
  Повторные unit IDs допустимы; временная зависимость без выбранной независимой
  единицы не объявляется IID. Confidence в (0,1), не менее двух units, finite inputs,
  n_resamples >= 100. Percentile CI, NumPy Generator, float64.
- `aggregate_units(unit_ids: Sequence[str], assignments: Sequence[str],
  outcomes: Sequence[float]) -> tuple[UnitOutcome, ...]` в randomized starter.
  `UnitOutcome(unit_id: str, arm: str, mean_outcome: float, count: int)`;
  arms A/B, один arm на unit, deterministic ID order, finite nonempty data.
- `validate_evidence(root: Path) -> None` paired evidence: snapshot/split IDs,
  labels+predictions → выбранный per-row loss → effect; CI сверяется с сохранёнными
  resample indices и unit policy, не с произвольными числами из JSON.

- [ ] Student tests: paired equality => effect/CI 0; постоянное ухудшение B на 2 =>
  effect/CI 2; unequal cluster sizes не меняют unit weighting; одинаковый seed

  Тест alignment использует ненулевые неодинаковые парные differences.

  learner models. Explain CI vs effect size, practical threshold, slices/support,

- [ ] Add A/A/A-B local synthetic example с назначением **по объекту**, несколькими
  событиями/объект и фиксированным горизонтом. Student test отклоняет смешанный arm;
  не требовать p-value < 0.05 или «отсутствия разницы» в каждом A/A seed.

## Проверенная техническая опора

Проверено 30.09.2026; API дополнительно проверять локальным smoke на pinned версиях.

- [PyTorch saving/loading](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html):
  различие inference state и optimizer state для продолжения. Порядок sampler и
  RNG — дополнительные требования нашего воспроизводимого CPU-эксперимента.
- [PyTorch SDPA 2.14](https://docs.pytorch.org/docs/2.14/generated/torch.nn.functional.scaled_dot_product_attention.html):
  boolean True означает доступ; dropout задаётся явно; mask convention нельзя
  смешивать с key_padding_mask. All-masked ValueError — наш учебный контракт.
- [sklearn calibration](https://scikit-learn.org/stable/modules/calibration.html),
  [ensembles](https://scikit-learn.org/stable/modules/ensemble.html),
  [leakage](https://scikit-learn.org/stable/common_pitfalls.html): выбранные методы
  есть в существующем стеке; fit preprocessing/calibration не использует test.
- [NumPy Generator.choice](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.choice.html):
  локальный seeded resampling не требует новой зависимости SciPy.
