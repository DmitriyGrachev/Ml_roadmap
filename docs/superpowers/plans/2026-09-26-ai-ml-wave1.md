# AI/ML Wave 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** расширить готовый roadmap честным зачётом и двумя самостоятельными модельными лабораторными.

**Architecture:** существующий каталог/CLI, opt-in training group, независимые labs и небольшой мост. Unit/CPU smoke/real evaluation имеют разные статусы.

**Spec:** [Согласованная архитектура](../specs/2026-09-26-ai-ml-wave1-design.md).

## Global Constraints

- Существующие student implementations, exercise contracts и progress markers не перезаписывать.
- Новые задания оставлять незавершёнными. Не создавать готовые отчёты ученика.
- Никаких загрузок моделей/данных при import, обычном pytest или uv sync.
- `training` opt-in; tracking, LoRA, serving, RAG integration остаются PLANNED.
- Работать в `codex/ai-ml-wave1`, не коммитить и не публиковать без нового запроса.

## Review Focus

- Strict check не должен пропускать xfail/skip в setup/collection или нулевую collection.
- Проверка одного ID не зависит от TODO соседнего задания.
- Training не попадает в default install; missing imports не обрушивают base collection.
- Отчёт с placeholder/несуществующим checkpoint не выдаётся за выполненный эксперимент.
- Ни smoke, ни случайный encoder не выдаются за прикладное качество настоящей модели.
