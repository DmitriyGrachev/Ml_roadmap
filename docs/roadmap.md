# Roadmap

This roadmap develops an experienced Java and Spring engineer's Python and AI engineering skills through active work rather than broad survey material. The first implemented learning wave will cover Modules 01–03; later modules retain a visible destination without representing completed courseware.

## Learning sequence

1. **Module 01 — Python core:** native Python object semantics, collections, functions, typing, data modeling, I/O, generators, decorators, testing, and async I/O.
2. **Module 02 — Production Python and FastAPI:** API composition, Pydantic models, dependencies, observability, SQLAlchemy, PostgreSQL boundaries, testing, and delivery.
3. **Module 03 — Data foundations:** NumPy, Pandas, data quality, practical statistics, leakage-aware splits, and fraud metrics.
4. **Module 04 — Machine Learning:** [planned curriculum](../modules/04_machine_learning/README.md).
5. **Module 05 — LLM Engineering:** [planned curriculum](../modules/05_llm_engineering/README.md).
6. **Module 06 — Retrieval-Augmented Generation:** [planned curriculum](../modules/06_rag/README.md).
7. **Module 07 — Agents:** [planned curriculum](../modules/07_agents/README.md).
8. **Module 08 — Production AI:** [planned curriculum](../modules/08_production_ai/README.md).

## Banking AI Lab

One synthetic-data project links the modules without hiding the learning goal behind framework ceremony. It progresses through CSV parsing and validation, analytics and JSON reporting, NumPy/Pandas analysis, FastAPI operations, PostgreSQL persistence, integration tests, and exploratory notebooks. Money stays decimal at domain and persistence boundaries; timestamps are timezone-aware.

## Start and track

Follow the [Windows and PyCharm setup](setup.md), then work from the planned first lesson path: `modules/01_python_core/00_environment/README.md`. Update the manual [progress checklist](../progress.md) as lessons are completed.
