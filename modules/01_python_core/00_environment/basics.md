# Первые строки Python: от выражения к небольшой программе

Начните здесь после [настройки окружения](README.md), **до** Object Model.
Предыдущий опыт программирования не требуется. Цель — прочитать короткую программу,
вручную проследить её выполнение и написать свою вариацию. Подробное устройство
имён/объектов, коллекций и типов уже разобрано в следующих уроках: здесь только вход.

## 1. Выражение даёт значение, инструкция выполняет действие

Предскажите `2 + 3 * 4`: 14 или 20? Умножение выполняется раньше сложения;
`(2 + 3) * 4` даёт 20. **Выражение (expression)** вычисляется в значение.
Интерпретатор (interpreter) исполняет Python-код. В терминале из корня проекта:

```powershell
uv run python
```

Появится приглашение `>>>`. Введите код после него, сам знак `>>>` не копируйте:

```python
2 + 3 * 4
label = "oak"
len(label)
print(label)
```

Интерактивная консоль покажет 14, затем 3, затем `oak`; присваивание само ничего
не печатает. `"oak"` — строка (string), `3` — целое число (integer).
`len(label)` вызывает функцию (function call), возвращающую длину строки.
Инструкция `label = "oak"` связывает имя с результатом правой части.
Разницу имени и объекта подробно изучите в [Object Model](../01_object_model/README.md).

`=` присваивает, `==` сравнивает: `len(label) == 3` даёт `True` — истину;
`len(label) > 6` даёт `False` — ложь. Это логические значения (booleans).
`and`, `or`, `not` означают «и», «или», «не». Например, `3 >= 1 and 3 <= 6` — True.
`#` начинает комментарий до конца строки. Выйдите из консоли командой `exit()`.

В обычном `.py` файле результат голого `2 + 3 * 4` не выводится:
для вывода нужен `print(...)`. Файл — последовательность инструкций (statements),
обычно выполняющихся сверху вниз. Исключения из этого порядка — ветвления,
циклы и вызовы функций, которые разберём сейчас.

## 2. Выбираем одну ветку: if / elif / else

Задача: обрабатывать подписи деревьев для маленькой выставки. У пустой строки
нет подписи, длинную нужно проверить, короткую — подготовить к печати.
`.strip()` возвращает строку без внешних пробелов, `.upper()` — в верхнем регистре.
Точка выбирает операцию строки; `()` запускают её. Внутренние пробелы остаются.

```python
raw = " oak "
label = raw.strip()
if label == "":
    action = "skip"
elif len(label) > 6:
    action = "review:long"
else:
    action = "keep:" + label.upper()
print(action)
```

`""` — пустая строка. `+` соединяет строки. Прежде чем запускать, заполните
мысленно колонку «ветка» для `" oak "`, `""`, `"sequoia"`.

```text
raw → strip → label пустая? ── да → skip
                      │ нет
                      ↓
                 длина > 6? ── да → review:long
                      │ нет
                      ↓
                 upper → keep:...
```

| raw | label после strip | проверка пустоты | длина > 6 | результат |
| --- | --- | --- | --- | --- |
| `" oak "` | `"oak"` | False | False | `keep:OAK` |
| `""` | `""` | True | не выполняется | `skip` |
| `"sequoia"` | `"sequoia"` | False | True | `review:long` |

**Ветвление (branching)** выбирает путь: `if` проверяет первое условие, `elif`
проверяется только если прежние ложны, `else` — оставшийся случай. Здесь за один
проход выполняется ровно одна ветка. Три отдельных `if` имеют другой смысл:
поздняя ветка может перезаписать прежний результат.

Двоеточие открывает блок (block), **отступ (indentation)** определяет, что в него
входит. Здесь четыре пробела; не смешивайте tabs и пробелы. В Java блок обычно
ограничен `{ ... }`, в Python перенос строки с отступом — часть синтаксиса.
`print(action)` без отступа выполняется после выбранной ветки.

Ошибка: сравнить `raw == ""`, забыв strip: строка из пробелов ошибочно становится
подписью. Вариация: предскажите ветку для `" cedar "` и для ровно шести символов.
Почему граница `> 6` отличается от `>= 6`?

## 3. Обрабатываем несколько элементов: for и range

Список (list) записывается в квадратных скобках: `["oak", "pine"]`.
Это упорядоченная последовательность. Пока достаточно обходить её целиком:

```python
labels = ["oak", "pine", "elm"]
for label in labels:
    print(label)
print("done")
```

Сначала `label` получает `"oak"`, затем `"pine"`, затем `"elm"`. Тело цикла (loop
body) выполняется один раз для каждого элемента; `done` выводится один раз после
цикла. Для пустого списка тело не выполняется. Не нужны ручное увеличение индекса
и обращение `labels[i]`, если нужен сам элемент.

`range(1, 4)` — последовательность целых 1, 2, 3: правая граница исключается.
`list(range(1, 4))` превращает её в список `[1, 2, 3]`. Предскажите вывод:

```python
total = 0
for number in range(1, 4):
    total = total + number
print(total)
```

| шаг | number | total до | total после |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |

`total` — накопитель (accumulator). Если написать `total = 0` **внутри** цикла,
прошлые результаты исчезают: последним станет 3 вместо 6. Вариация: замените
`range(1, 4)` на `range(1, 5)`, предскажите число шагов и итог до запуска.
Для остановки раньше конца есть `break`, для пропуска оставшейся части текущего
шага — `continue`. Они не обязательны для первой самостоятельной задачи.

## 4. Повторяем, пока условие истинно: while

Если заранее есть последовательность — обычно проще `for`. Когда остановка зависит
от изменяемого состояния, пригодится `while`:

```python
remaining = 3
while remaining > 0:
    print(remaining)
    remaining = remaining - 1
```

| проверка remaining > 0 | напечатано | remaining после тела |
| --- | --- | --- |
| 3 > 0 → True | 3 | 2 |
| 2 > 0 → True | 2 | 1 |
| 1 > 0 → True | 1 | 0 |
| 0 > 0 → False | ничего | 0 |

Условие проверяется **до** каждого шага. Без уменьшения `remaining` возникнет
бесконечный цикл (infinite loop). Вариация: что напечатается при начальном 0?
При условии `remaining >= 0`? Не запускайте заведомо бесконечный вариант.

## 5. Функция называет действие и возвращает результат

Вместо копирования ветвления в каждом месте выделим функцию. В демонстрации есть
её законченная реализация. Здесь синтаксис без необязательных аннотаций типов:

```python
def label_action(raw):
    label = raw.strip()
    if label == "":
        return "skip"
    elif len(label) > 6:
        return "review:long"
    else:
        return "keep:" + label.upper()


action = label_action("pine")
print(action)
```

`def` определяет функцию, `raw` — параметр (parameter), `"pine"` при вызове —
аргумент (argument). Определение не выполняет тело; оно запускается при вызове.
`return` немедленно завершает этот вызов и отдаёт значение вызывающему коду.
Для `"pine"` в `action` попадёт `"keep:PINE"`. `print` лишь выводит текст;
замена `return` на `print` не вернёт строку. Без выполненного `return` функция
возвращает `None`: это отдельное значение, которое подробнее разберёт Object Model.

```text
вызов label_action("pine")
       raw = "pine" → strip → if False → elif False → else
                                                     ↓ return
action = "keep:PINE" ←────────────────────────────────┘
print(action) → экран
```

В полном `basics_demo.py` увидите `raw: str` и `-> str`: это аннотации ожидаемых
типов параметра и результата. Они помогают читать код и проверять его mypy;
сами по себе не проверяют вход во время выполнения. `list[str]` — список строк,
`tuple[str, str]` — пара строк, `(raw, result)` — такая пара. Подробности — позже
в [Collections](../02_collections/README.md) и [Typing](../04_typing/README.md).
В примере `trace.append(...)` добавляет одну пару в конец нового списка.

`import math` загружает модуль (module) стандартной библиотеки; `math.ceil(2.3)`
даёт 3. Файлы с Python-кодом также являются модулями. Не называйте свой файл
`math.py` или `pytest.py`: он может заслонить библиотеку. Ничего устанавливать для
`math` не нужно. Условие `if __name__ == "__main__": main()` внизу демонстрации
запускает `main` при прямом запуске, а при импорте для тестов ничего не печатает.
Сложные формы import и устройство пакетов сейчас не требуются.

Сначала разберите по очереди `label_action`, `trace_labels`, `countdown`, затем

пустоту и пробелы. `f"...{value}..."` вставляет значение в текст. Прогнозы и таблицы
выше показывают те же ветки и значения, что запускаемый код.

## 7. Самостоятельный перенос

В [практике](practice/README.md), target `python-control-flow`, нужно **посчитать**
подходящие подписи, а не копировать готовое действие для одной строки. Стартовый
файл и ваши выводы не заполнены. До решения `test` допускает xfail, `check` не зачтёт TODO.
После первой попытки переходите к [Object Model](../01_object_model/README.md),
затем к Collections и Functions; прежние уроки не заменяются этим введением.
После pytest-урока вернитесь и добавьте собственный тест на другую границу.

Проверьте понимание своими словами:

1. Почему выражение видно в консоли, но не печатается само в `.py` файле?
2. Как отступ меняет число выводов `done`?
3. Почему `range(1, 4)` делает три шага?
4. В какой момент пустой `for` и `while` с начальным 0 выполняют тело?
5. Что прекращает `return`, а что прекращает `break`?
6. Почему напечатанная строка ещё не является возвращённой строкой?
7. Какой вход отличает `> minimum` от `>= minimum`?
