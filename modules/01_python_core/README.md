# Module 01 — Python core for Java developers

This module moves from a reliable local workflow through Python's data model,
collections, functions, types, I/O, generators, decorators, testing, and async
I/O. Read lessons in numeric order and run each `example.py` before beginning
the exercises that follow in later tasks.

| Lesson | Focus |
| --- | --- |
| 00 | Environment and workflow |
| 01 | References, mutability, and equality |
| 02 | Collections and idiomatic data processing |
| 03 | Functions and callbacks |
| 04 | Types and protocols |
| 05 | Classes and dataclasses |
| 06 | Exceptions and I/O |
| 07 | Iterators and generators |
| 08 | Decorators |
| 09 | pytest fundamentals |
| 10 | asyncio I/O concurrency |

Run all runnable examples with `uv run pytest modules/01_python_core/tests -q`.
