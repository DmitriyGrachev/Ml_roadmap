# Module 05 — LLM Engineering

## Scope

This future module will focus on application-level LLM integration: prompt and output contracts, structured responses, evaluation sets, tool boundaries, latency and cost trade-offs, and safe handling of customer-support-style documents.

## Prerequisites

Complete the implemented Python core and backend modules, including typed boundaries, API validation, async I/O, tests, and configuration practices. Data foundations should be sufficient to reason about evaluation samples and failure slices.

## Planned outcomes

You will be able to build an LLM feature with explicit input and output contracts, measure it against a small evaluation set, and identify when deterministic software or human review is the better boundary.

Exercises are intentionally deferred.
