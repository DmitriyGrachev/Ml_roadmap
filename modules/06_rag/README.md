# Module 06 — Retrieval-Augmented Generation

## Scope

This future module will cover document ingestion, chunking, metadata, retrieval quality, grounded generation, citations, and evaluation for support and policy-document use cases.

## Prerequisites

Complete the planned data foundations and LLM engineering sequences. Familiarity with APIs, persistence boundaries, tests, and document-oriented data is expected.

## Planned outcomes

You will be able to design a retrieval pipeline with measurable retrieval and answer quality, trace an answer to its source material, and distinguish retrieval failures from generation failures.

Exercises are intentionally deferred.
