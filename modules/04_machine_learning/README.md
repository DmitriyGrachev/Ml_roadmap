# Module 04 — Machine Learning

## Scope

This future module will connect the data-foundations work to supervised learning workflows: feature design, baseline models, evaluation choices, error analysis, and reproducible experiments using synthetic financial-risk examples.

## Prerequisites

Complete the planned Python core, production Python, and data foundations sequences. You should be comfortable reading tabular data, checking data quality, and explaining leakage, class imbalance, and the limits of accuracy.

## Planned outcomes

You will be able to prepare a defensible baseline, choose evaluation metrics that match a business risk, compare experiments without leakage, and communicate the limitations of a model before operational use.

Exercises are intentionally deferred.
