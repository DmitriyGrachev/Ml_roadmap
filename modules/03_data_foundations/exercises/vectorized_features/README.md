## Задание

Меняйте [starter.py](starter.py). Обе функции возвращают новые массивы и не меняют
входы, включая срезы другого массива с произвольными strides.

`masked_standardize(values, observed)` принимает непустую двумерную `float64`
матрицу `(n, d)` и булеву маску **точно той же формы**. Маска авторитетна: `False`
исключает ячейку даже при конечном значении; в исключённых ячейках допустимы NaN
и бесконечность. Все наблюдаемые значения должны быть конечными. Возврат:
`(standardized, mean, scale, count)` форм `(n, d), (d,), (d,), (d,)`, первые три
`float64`, последняя `int64`. Считайте среднее и стандартное отклонение отдельно
для каждого столбца по наблюдаемым строкам, с `ddof=0`. Для пустого столбца
`mean=0, scale=1, count=0`; для константного `scale=1`. Ненаблюдаемые выходные
ячейки всегда нулевые. Неверную форму, пустую ось, небулеву маску и наблюдаемый
NaN/inf отклоняйте через `ValueError`.

`topk_cosine(queries, candidates, k)` принимает конечные непустые матрицы
`float64` форм `(m, d)` и `(n, d)` с одинаковым числом признаков. Возвращает
`(indices, scores)` формы `(m, k)` с типами `int64` и `float64`. Нормируйте по
строкам. Cosine при хотя бы одном нулевом векторе равен **нулю**. Сортируйте по
убыванию score, затем по возрастанию исходного индекса кандидата: это существенно
для ничьих на границе top-k. `k` — целое, не `bool`, `1 <= k <= n`. Пустые оси,
NaN/inf, несовместимые формы и неверный `k` дают `ValueError`.

## Критерии переноса

Сформулируйте тест с ненулевым исключённым значением и тест с отрицательным cosine.
Объясните, почему нулевой кандидат может обойти отрицательный. Оцените память для
`m=10000, n=100000, d=128` и предложите batch size с учётом доступной памяти.
Проверки арифметики автоматические; выбор батча и объяснение поведения на новом
домене оценивает человек. Артефакты и дополнительные зависимости здесь не нужны.
