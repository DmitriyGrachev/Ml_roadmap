# Aggregate randomized experiment units

Сложность: средняя · 45–70 минут.

## Перед началом

- `data-paired-model-comparison`: [независимые единицы и разности](../paired_model_comparison/README.md).
- `data-statistical-profile`: [описание распределения и поддержки](../../04_practical_statistics/exercises/statistical_profile/README.md).

## Задача

Реализуйте `aggregate_units(unit_ids, assignments, outcomes)` в `starter.py`. Каждая запись — событие объекта за заранее фиксированный горизонт. Назначение A/B делают **один раз объекту**, после чего все его события сохраняют тот же arm. Верните `tuple[UnitOutcome, ...]` в порядке ID: ID, arm, средний outcome событий объекта и число событий. Пустые или разные длины, пустые ID, arm вне A/B, неконечные outcomes и смешанное назначение одному ID отклоняйте через `ValueError`. Исходные последовательности не меняйте.

Среднее по всем событиям при разном числе событий на объект отвечает другому вопросу и может дать крупным объектам чрезмерный вес. Сначала определите единицу рандомизации и фиксированный горизонт наблюдения, затем сравнивайте единицы. Если данные идут по времени, соседние события одного объекта не становятся независимыми от записи в отдельных строках.

## Локальный A/A и A/B

`example.py` создаёт синтетические измерения 24 датчиков: один arm на датчик, три события на каждый датчик и одинаковый горизонт. В A/A воздействие не вводится; в A/B добавляется небольшой сдвиг для B. Случайная A/A разность не обязана быть ровно нулём, а p-value < 0.05 не является критерием исправности каждого seed. Не подбирайте seed, пока один запуск не понравится.

Запуск: `.venv/Scripts/python.exe -m modules.03_data_foundations.exercises.randomized_experiment.example`. Это пример с датчиками, а не готовый ответ для ваших объектов.

## Работа и критерий

Меняйте только `starter.py`. Этапы: (1) проверьте все длины и значения; (2) запоминайте arm при первом событии ID и отвергайте конфликт; (3) суммируйте и считайте среднее внутри ID; (4) сортируйте результат. Не используйте события как независимые наблюдения при последующем статистическом выводе.

Из корня репозитория:

```powershell
.venv/Scripts/python.exe scripts/learn.py test data-randomized-experiment
.venv/Scripts/python.exe scripts/learn.py check data-randomized-experiment
.venv/Scripts/python.exe -m pytest modules/03_data_foundations/exercises/randomized_experiment -q -rx
```

Unit tests проверяют агрегацию и запрет смешанного arm; синтетический пример — локальный smoke; реальный A/B результат требует отдельной оценки данных и рандомизации; интерпретация эффекта и ограничений требует review. До завершения TODO `test` показывает xfail, `check` отклоняет незавершённую работу. Готово, когда тесты проходят без xfail и вы можете объяснить выбор единицы и горизонта.
