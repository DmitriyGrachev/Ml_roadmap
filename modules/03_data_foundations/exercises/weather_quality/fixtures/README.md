# Вымышленные погодные наблюдения для EDA

Файл [`eda_weather.csv`](eda_weather.csv) — постоянный учебный набор данных,
составленный вручную. Все станции, даты и измерения вымышлены: записи не
получены из настоящей метеослужбы и не относятся к реальным местам или людям.
Файл достаточно мал, чтобы рассмотреть отдельные строки, но содержит несколько
дней и станций. По нему нельзя делать выводы о реальной погоде или климате.

Заголовок CSV: `station,day,temperature_c,rainfall_mm`. Поле `station` задаёт
категорию, `day` должно содержать календарную дату в формате `YYYY-MM-DD`,
температура измеряется в градусах Цельсия (°C), осадки — в миллиметрах (мм).
Пропущенные значения представлены пустыми полями CSV. Сохраняйте исходный
текст и порядок строк, пока решаете, какие значения можно разобрать и
использовать.

В файле намеренно есть пропущенные или некорректные значения,
повторяющиеся пары «станция — день» и как минимум одно необычное, но
правдоподобное измерение. Некоторые проблемы важны для одного графика,
но не мешают другому. Перед интерпретацией графиков зафиксируйте правила
качества и отбора строк. Практикум не содержит готовых итоговых подсчётов
проблем, очищенных строк или выводов по графикам.
