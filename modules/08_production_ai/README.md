# Module 08 — Production AI

## Scope

This future module will bring AI features into production concerns: deployment, telemetry, evaluation in operation, privacy, cost controls, incident response, and continuous improvement.

## Prerequisites

Complete the implemented backend and data foundations modules, followed by the planned LLM, retrieval, and agent sequences. You should understand test automation, configuration, persistence, API operations, and the difference between offline and live evaluation.

## Planned outcomes

You will be able to define operational quality signals, ship an AI-backed service with clear safeguards, and make trade-offs among latency, cost, privacy, reliability, and human oversight.

Exercises are intentionally deferred.
