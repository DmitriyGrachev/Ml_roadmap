# Module 07 — Agents

## Scope

This future module will explore bounded agent workflows: tool contracts, state, planning, handoffs, observability, approval points, and recovery from tool or model failures.

## Prerequisites

Complete the planned LLM engineering and retrieval material. You should be comfortable designing API boundaries, validating data, writing tests, and separating deterministic operations from probabilistic decisions.

## Planned outcomes

You will be able to build a narrow, observable agent workflow with explicit tools and stop conditions, then evaluate it for reliability rather than relying on an impressive single demonstration.

Exercises are intentionally deferred.
